# 🖨️ บันทึกมิเตอร์การพิมพ์

เว็บแอพที่ใช้แทน Google Form "แบบฟอร์มบันทึกมิเตอร์การพิมพ์" โดยมีฟิลด์เหมือนฟอร์มเดิมทุกช่อง
(พนักงาน + จำนวนแผ่นของ 5 วัสดุ × สี/ขาวดำ)

## มีอะไรดีกว่า Google Form

- **ใส่ได้หลายงาน เว็บบวกให้เอง** พิมพ์ตัวเลขแล้วกด Enter หรือปุ่ม ＋ ใส่งานถัดไปได้เรื่อยๆ
  หรือพิมพ์ต่อกันในช่องเดียว เช่น `12+30+5` หรือ `12 30 5` ก็ได้ ยอดรวมขึ้นให้ทันที (เช่น `12 + 30 + 5 = 47`)
- **ใส่ผิดลบได้** กด ✕ ที่ตัวเลขที่ใส่ผิด
- **ไม่ต้องใส่ "-"** ช่องไหนไม่ได้พิมพ์ก็ปล่อยว่าง ระบบบันทึกเป็น 0 ให้
- **ตรวจทานก่อนส่ง** มีตารางสรุปให้ดูก่อนกดยืนยัน พร้อมรายละเอียดว่าแต่ละยอดมาจากงานไหนบ้าง
- **จำชื่อคนพิมพ์** และจำตัวเลขที่กรอกค้างไว้ แม้ปิดหน้าเว็บไปก่อน
- **หน้าประวัติ** ดูยอดวันนี้ / เมื่อวาน / 7 วัน / เดือนนี้ กรองตามพนักงาน และดาวน์โหลด CSV ได้
  (หัวคอลัมน์ CSV เหมือนชีตคำตอบของ Google Form เดิม)
- **ลบผิดกู้คืนได้** ปุ่ม "ลบ" จะย้ายรายการไป 🗑️ ถังขยะ (แท็บ `ถังขยะ` ในชีต) ไม่ได้ลบทิ้งจริง
  กด "เลิกทำ" ทันทีหลังลบ หรือเข้าไปกด "กู้คืน" ในถังขยะภายหลังก็ได้ ระบบบันทึกด้วยว่าใครลบและลบเมื่อไร
  ถ้าจะลบรายการของคนอื่น จะมีคำเตือนให้เห็นก่อน
- ใช้บนมือถือสะดวก ปุ่มใหญ่ รองรับโหมดมืด

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html`, `styles.css`, `app.js` | ตัวเว็บ (ไฟล์ static ล้วน ไม่ต้อง build) |
| `config.js` | ตั้งค่ารายชื่อพนักงาน, ประเภทวัสดุ และลิงก์ Google Sheet |
| `apps-script/Code.gs` | สคริปต์ฝั่ง Google Sheet สำหรับเก็บข้อมูลรวมของทุกคน |

## วิธีใช้งาน

### 1) เชื่อม Google Sheet (เพื่อให้ทุกเครื่องเห็นข้อมูลเดียวกัน)

ถ้าไม่ได้ตั้งค่าส่วนนี้ เว็บยังใช้ได้ แต่ข้อมูลจะเก็บอยู่ในเบราว์เซอร์ของเครื่องที่กรอกเท่านั้น

1. สร้าง Google Sheet ใหม่ (หรือใช้ชีตเดิม)
2. เมนู **ส่วนขยาย → Apps Script** แล้ววางโค้ดจาก `apps-script/Code.gs` ทับทั้งหมด แล้วกดบันทึก
3. กด **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่**
   - ประเภท: **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
4. อนุญาตสิทธิ์ แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)
5. เปิด `config.js` แล้ววาง URL ใน `SHEET_API_URL`

ข้อมูลจะถูกบันทึกในแท็บ `บันทึกมิเตอร์` (ระบบสร้างให้อัตโนมัติ) โดยมีคอลัมน์เหมือนฟอร์มเดิม
บวกคอลัมน์ "รวม", "รายละเอียด" (ตัวเลขแต่ละงาน) และ "ID"

> ถ้าเน็ตหลุดตอนกดส่ง ข้อมูลจะเก็บไว้ในเครื่องก่อน (ขึ้น ⏳ รอส่งขึ้นชีต) แล้วส่งให้อัตโนมัติเมื่อกลับมาออนไลน์

> ⚠️ ทุกคนที่มี URL ของเว็บแอปจะอ่าน/เพิ่ม/ลบข้อมูลได้ อย่าเผยแพร่ลิงก์ให้คนนอก

### 2) เปิดเว็บให้ทีมใช้ (GitHub Pages)

1. ใน GitHub ไปที่ **Settings → Pages**
2. Source: **Deploy from a branch** เลือก branch ที่มีไฟล์เหล่านี้ และโฟลเดอร์ `/ (root)`
3. รอสักครู่จะได้ลิงก์ เช่น `https://yimwannsticker.github.io/yimwannsticker-form/`
4. บนมือถือ กด "เพิ่มไปยังหน้าจอหลัก" เพื่อใช้เหมือนแอพ

ทดสอบในเครื่อง: `python3 -m http.server` แล้วเปิด http://localhost:8000

## อัปเดตโค้ด Apps Script

เมื่อ `apps-script/Code.gs` มีการเปลี่ยนแปลง ให้วางโค้ดใหม่ทับใน Apps Script แล้วกด
**การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ✏️ → เวอร์ชัน: เวอร์ชันใหม่ → การทำให้ใช้งานได้**
(URL `/exec` เดิมใช้ต่อได้ ไม่ต้องแก้ `config.js`)

ถังขยะไม่ลบตัวเองอัตโนมัติ ถ้าต้องการล้างจริงๆ ให้เจ้าของลบแถวในแท็บ `ถังขยะ` ของชีตเอง

## แก้รายชื่อพนักงาน / วัสดุ

แก้ใน `config.js` ได้เลย
ถ้าเพิ่มหรือเปลี่ยน `id` ของวัสดุ ต้องแก้รายการ `FIELDS` ใน `apps-script/Code.gs` ให้ตรงกัน แล้ว Deploy เวอร์ชันใหม่
